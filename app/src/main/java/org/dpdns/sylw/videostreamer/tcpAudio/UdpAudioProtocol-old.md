# UDP 音频传输协议设计文档

## 1. 握手阶段
客户端启动时发送 1 个配置包（序号固定为 0）：
| 字段 | 长度 | 说明 |
| :--- | :--- | :--- |
| **序号** | 1 Byte | 0x00 (固定为握手包) |
| **采样率索引** | 1 Byte | 0x01 (48000Hz) | 0x00 44100
| **声道数** | 1 Byte | 0x02 (立体声) | 0x01 单声道
| **预留** | 1 Byte | 0x00 |

## 2. 数据传输阶段 (UDP Payload)
每帧音频数据发送 3 次冗余包：
| 字段 | 长度 | 说明 |
| :--- | :--- | :--- |
| **序号** | 1 Byte | 0x01 - 0xFF (循环递增) |
| **PCM 数据** | N Bytes | 原始音频采样数据 |

## 3. 冗余与处理
- **包三送**: 每帧数据连续发送 3 次相同序号的数据包。
- **接收端处理**: 维护 `lastProcessedSeq`，丢弃重复及乱序包。
